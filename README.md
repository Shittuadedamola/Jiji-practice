Jiji.ng E-Commerce Website Clone

A frontend practice project recreating the user interface of Jiji.ng, an online marketplace where users can browse products across different categories.

ABOUT THE PROJECT

This project is a clone of the Jiji.ng website, built to improve my frontend development skills and gain practical experience recreating a real-world marketplace interface.

The project focuses on the website's layout, navigation, search interface, product listings, and responsive design across different screen sizes.

Note: This is an educational project created for practice purposes. It is not affiliated with or endorsed by Jiji.ng.

TECHNOLOGIES USED

Tailwind CSS

JavaScript
